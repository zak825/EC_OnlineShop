# 購入画面_処理手順

凡例（資料の記号との対応）

| 資料の記号 | 図での表し方 |
|---|---|
| 開始・終了（●） | `(( ))` |
| ユーザーの操作 | `[/ /]` |
| 処理内容（角丸） | `( )` |
| 分岐（◇） | `{ }` |
| 画面 | `[[ ]]` |

---

```mermaid
flowchart TD
    S((開始)) --> A[/購入画面を開く/]
    A --> B{ログイン済みか}
    B -- NO --> R(商品IDを戻り先として<br>URLパラメータに付ける)
    R --> LOGIN[[ログイン画面]]
    LOGIN -- ログイン成功 --> C
    B -- YES --> C{商品が存在するか}
    C -- NO --> E1(「商品が見つかりません。」) --> MAIN1[[メイン画面]]
    C -- YES --> D{未購入か<br>BuyerName・SoldDate が未設定}
    D -- NO --> E2(購入ボタン非表示<br>「この商品は売り切れです。」)
    D -- YES --> F{自分の出品か<br>Sales.Userid = ログインユーザー}
    F -- YES --> E3(購入ボタン非表示<br>「自分の出品した商品は購入できません。」)
    F -- NO --> G(商品情報を表示<br>購入数量は 1)
    E2 --> P[[購入画面]]
    E3 --> P
    G --> P
    P --> U{ユーザーの操作}
    U -- 戻る --> MAIN2[[メイン画面]]
    U -- 購入 --> H(商品IDをセッションに保存)
    H --> CONF[[購入確認画面]]
    MAIN1 --> END((終了))
    MAIN2 --> END
    CONF --> END
```

---

## 補足：ログイン後の戻り先

- ログイン画面へ飛ばすときは、商品IDを戻り先としてURLパラメータに付ける（例：`/login?return=/purchase?productId=123`）
  - セッション切れの場合はセッションに保存した値も消えているため、URLで渡す
- ログイン成功時に戻り先があればそこへ遷移し、なければメイン画面へ遷移する
- 戻り先URLは自サイト内のパスだけ許可する（外部サイトへ飛ばされる対策）

## 補足：商品情報取得のSQL（例）

```sql
SELECT s.ProductID, s.ProductName, s.Price, s.Userid,
       s.BuyerName, s.SoldDate,
       g.GenreName, u.UserName AS SellerName
FROM Sales s
JOIN Genre    g ON s.GenreCode = g.GenreCode
JOIN UserData u ON s.Userid    = u.Userid
WHERE s.ProductID = @ProductID;
```
